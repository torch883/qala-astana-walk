# Приватность и надёжность в коде

- **Локация.** Широта округляется до 0,001°, долгота до 0,002° — сетка около 111 × 140 м. Это не гарантия анонимности. Точка обрабатывается в памяти страницы и запроса; приложение не записывает её в файл или логи. Access log при штатном запуске отключён.
- **История.** Нет аккаунтов, аналитики и постоянной истории. Последние шесть реплик живут в памяти браузера и передаются API для уточнений. После обновления страницы история исчезает. «Очистить диалог» очищает текущий ответ, точку и реплики. Ответы API имеют `Cache-Control: no-store`.
- **Сохранённое.** Только по нажатию: ID, название, категория, источник и дата публичного POI в localStorage данного браузера. Не сохраняются координаты пользователя, расстояния, запрос, объяснение с предпочтениями, расписание или дедлайн. Старые записи мигрируют на этот список полей, повреждённые пропускаются. Расписание нужно проверить заново.
- **Внешние сервисы.** Поиск и карта основного сайта локальные, Leaflet включён в репозиторий. Gemini при явной настройке получает текст после удаления координат/телефоноподобных строк, предпочтения и публичных кандидатов. Это не полное удаление персональных данных; личные сведения вводить не следует. Ключ хранится в `.env`, передаётся в заголовке, не выводится в ответах. Публичные источники открываются по нажатию пользователя.
- **Погода.** Open-Meteo получает фиксированный центр Астаны и выбранную дату. Точка пользователя не передаётся. Ручные погодные сценарии помечены как демо, а не прогноз. При ошибке сеть не подменяется выдуманной погодой: UI сообщает, что она не учтена. Основной API не сохраняет прогноз на диск.
- **Кэш.** На диск записываются только пять заранее определённых публичных демонстраций. Совпадают запрос, время, точка, ограничения и отпечаток данных; часы проверяются снова. При погодном контексте и явном дедлайне расчёт выполняется заново. Живые запросы в этот кэш не попадают.
- **Неопределённость.** Розетки, Wi-Fi, тишина, интерактивы и доступность не объявляются фактами без источника. Карточки разделяют сведения `poi_data` и идеи `generated_idea`, показывают дату и уверенность. «По расписанию открыто» не гарантирует фактическую работу организации.
- **Безопасность.** Ночью нужны `open/high` и расписание на весь визит; для открытых пространств — освещение. В суровую погоду предлагаются помещения и короткие участки по улице. Пересадка сохраняет резерв перед вылетом, но не проверяет визы, багаж и задержки рейса. Вредные запросы блокируются правилами ru/en/kk; это ограниченная защита, а не гарантия для любого перефразирования.
- **Инъекции.** Описания POI очищаются от явных инструкций и передаются как данные. LLM выбирает только разрешённые ID, коды идей и длительность. Факты собирает код; независимый валидатор проверяет ответ. Генерируемое обогащение не становится доказательством наличия услуги.
- **Обратная связь.** «Сообщить о неточности» передаёт ID POI и фиксированную причину. Сервер учитывает анонимный счётчик только в памяти, без аккаунта и свободного текста. Постоянное исправление делается отдельно в OSM по ссылке.

Прежний Streamlit-режим доступен отдельно: телеметрия отключена; его опциональная внешняя подложка раскрывает IP и область карты поставщику тайлов. Это не относится к локальной карте основного сайта.

Перед публичным пилотом нужны проверка мест людьми, реальная маршрутизация и доступность входов, вычитка казахского, нагрузочные тесты и отдельная оценка хранения данных выбранным LLM-провайдером.
