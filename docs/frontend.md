# Интерфейс и API QALA

Основной интерфейс объединён в `main` (merge `67d97d0`). FastAPI отдаёт SPA из `web/`, локальную библиотеку Leaflet и OSM-схему улиц. Node.js, внешний CDN и сборка не нужны. Запуск и зависимости — в [README](../README.md).

## Пользовательский экран

Ввод находится вверху внутри сайта. Ниже — параметры, кнопка применения, вкладки «Маршрут / Карта», реальные остановки и возвращение. «Прогулка», «Пересадка», «Сохранённое» переключаются нижним меню. На 390 px панель жюри свёрнута, после расчёта страница прокручивается к ответу. На широком экране панель находится слева.

Пересадка показывает крайнее время выезда из города и четыре отметки: прибытие в город, выезд, аэропорт, вылет. При отказе без маршрута таймер не показывается. Погодный бейдж различает ручной сценарий и Open-Meteo. Сценарий «мороз» содержит совет и короткий путь по улице; предполагаемые тёплые узлы имеют оговорки о часах.

Начальный экран — подписанный пример, а не вычисленный результат. Реальные остановки формируются из допустимого маршрута; число не дополняется до трёх искусственно. Клик по карте округляет новый старт и сбрасывает старый маршрут. Обновлённые параметры требуется применить.

## Контракт API

- `GET /api/health` — готовность, число POI, фактический backend поиска, предупреждение о fallback и режим генерации. `gemini_configured` означает наличие настроек, а не успешную проверку провайдера.
- `GET /api/presets` — пресеты, пять публичных сценариев, качество данных, runtime-статус, резерв аэропорта и начальное состояние кэша.
- `POST /api/recommend` — исходная Pydantic-схема `Answer`; `?details=true` — `{answer, presentation, debug}` для SPA.
- `GET /api/map-context` — локальный GeoJSON улиц и реки, без внешних тайлов.
- `POST /api/feedback` — `{poi_id, reason}`; причины `hours`, `location`, `accessibility`, `other`. Анонимный счётчик в памяти, не заявка на автоматическое исправление OSM.

```json
{
  "query": "А можно потише и без кофе?",
  "preset": "Центральный парк",
  "now": "2026-10-19T15:00:00+05:00",
  "duration_min": 60,
  "language": "ru",
  "history": ["Гуляю с ребёнком"],
  "demo_cache": false,
  "weather": "off"
}
```

Вместо пресета передайте `location: [lat, lon]`. `deadline` ограничивает возвращение к началу; `departure_at` задаёт вылет. `airport_transfer_min` — минимум 30/45/60 минут, используется максимум между ним и оценкой движка. Бюджет текста, включая «полчаса», ограничивается выбранным бюджетом UI. Максимум шесть реплик истории по 1500 символов; ошибки не повторяют текст запроса.

## Хранение и резервные режимы

Запрос, округлённая точка, история и debug живут в оперативной памяти. API отдаёт `Cache-Control: no-store`; сервер запускается без access log. После явного сохранения в localStorage попадают только ID, название, категория, источник и дата POI. Старые закладки автоматически очищаются от расстояний, предпочтений и расписания; повреждённые записи пропускаются. Часы и путь в сохранённом не выдаются как актуальные.

Без E5 работает TF-IDF; это видно в панели и RAG. Без Gemini — локальные правила и шаблоны. Дисковый демо-кэш ограничен точными публичными сценариями без погодного контекста и явного дедлайна. При ошибке HTTP может быть показан ранее полученный в этой вкладке ответ для тех же публичных параметров. Полный отказ сервера не позволяет рассчитать новый маршрут.
