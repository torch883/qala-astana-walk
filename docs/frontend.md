# Новый интерфейс QALA

Ветка `feat/qala-mobile-ui`, основана на `feat/weather-layover` (`464f405`). FastAPI отдаёт небольшой SPA без Node.js, сборки и внешних шрифтов. `make run` → http://127.0.0.1:8000. Windows: `Start-Demo.ps1` или команда uvicorn из README. Старое приложение: `make legacy`.

## Что изменено

- `web/`: телефон 540 px, цвета из референса, крупный заголовок, остановки с раскрытием, карта, чат, три раздела. Шрифт Inter при наличии, иначе Arial/Helvetica; дополнительных загрузок нет.
- Панель жюри вынесена из телефона. На 390 px она сворачивается, рамка исчезает, навигация закреплена снизу с safe-area. Контролы имеют фокус, крупные области нажатия; анимации отключаются при reduced-motion.
- `ui_service.py`: ограниченная история, уточнения «потише / без кофе», подбор допустимого подмаршрута с возвращением, рассчитанные метаданные и заголовок. При Gemini доступен отдельный структурированный заголовок; без ключа честно обозначен шаблон.
- `api.py`: один Engine на процесс, stateless-запросы, ошибки без эха текста/координат. Отметки о неточностях — только анонимные счётчики в памяти; кнопка не обещает исправление OSM.
- В `core/` добавлены необязательные параметры дедлайна, минимального трансфера и кэша на запрос. `rank` учитывает путь туда-обратно; в пересадке резерв до вылета не сокращается. Данные, индексы, исходные схемы и сценарии eval сохранены.

## API

`POST /api/recommend` возвращает исходную Pydantic-схему `Answer`. SPA явно использует `?details=true` и получает `{answer, presentation, debug}`. Поэтому дополнительные поля интерфейса не меняют исходный контракт. Swagger: `/docs`.

```json
{
  "query": "А можно потише и без кофе?",
  "preset": "Центральный парк",
  "now": "2026-10-18T15:00:00+05:00",
  "duration_min": 60,
  "language": "ru",
  "history": ["Гуляю с ребёнком"],
  "demo_cache": false,
  "weather": "off"
}
```

Вместо пресета можно передать `location: [lat, lon]`. Координаты округляются до обработки. `deadline` — крайнее возвращение к точке старта. Для пересадки `departure_at` — время вылета, `airport_transfer_min` — минимум 30/45/60 минут; берётся максимум между этим минимумом и оценкой существующего движка. На экране показан срок возвращения к точке высадки в городе, после которого начинается трансфер; резерв перед вылетом — минимум 120 минут.

`GET /api/presets` возвращает публичные пресеты, пять сценариев, качество данных и начальный режим кэша. `POST /api/feedback`: `{poi_id, reason}`; причины `hours`, `location`, `accessibility`, `other`. `GET /api/map-context` отдаёт имеющийся OSM GeoJSON.

## Приватность и честность

История и текущая точка находятся только в памяти страницы/запроса. В localStorage записываются только места или маршруты, явно сохранённые пользователем: без исходной точки, текста запроса, истории, debug и дедлайна. Сервер не пишет HTTP access log. У API стоит `Cache-Control: no-store`. После обновления страницы диалог исчезает, сохранённое остаётся в этом браузере.

Начальная картинка — подписанный пример оформления. В реальном результате число остановок определяется бюджетом; три места не рисуются ради сходства. Неизвестные часы обозначены явно. После изменения параметров требуется пересчёт. Карта — оценка по прямой с коэффициентом, не пошаговая навигация. Сохранённые карточки не подтверждают актуальность расписания.

## Карта и отличия от референса

Во время браузерной проверки CARTO `dark_all` вернул изображения с надписью `API KEY REQUIRED`. Вместо пустой карты включена локальная тёмная схема существующего снимка OSM: 1761 линия дорог и 18 линий реки. Leaflet 1.9.4 включён в `web/vendor/` с лицензией. Внешний сервис карты не получает IP/область просмотра. Нет зданий, постоянных подписей улиц и полной детализации CARTO; название дороги доступно при наведении.

Две итерации сравнения с исходным изображением: сначала подобраны размеры контролов, затем строка приватности перенесена над рамкой, чтобы вернуть заголовок и список к положениям референса. Основные цвета: `#E8E9E4`, `#232B26`, `#101B24`, `#CDE88A`. Системный шрифт и родные меню выбора могут отличаться от изображения. На странице добавлена панель жюри; фактический ответ может содержать одну остановку или отказ.
